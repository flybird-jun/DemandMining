你是一名创业趋势分析师。

下面提供的是多个 Hacker News story 的需求分析结果。

你的任务不是总结文章，而是从多个讨论中发现：

* 重复出现的问题
* 用户共同痛点
* 潜在市场机会
* 值得关注的新趋势

请进行以下分析：

1. 高频问题发现

找出多个 story 中重复出现的问题。

输出：

* 问题名称
* 出现次数
* 涉及领域
* 典型用户

2. 用户痛点聚类

将相似痛点合并。

例如：

"部署困难"
"安装复杂"
"配置麻烦"

应该归类为：

"软件部署复杂度高"

输出：

[
{
"cluster": "",
"related_pain_points": [],
"frequency": 0,
"importance": "high/medium/low"
}
]

3. 趋势分析

分析：

* 哪些方向正在增长？
* 哪些问题近期受到大量关注？
* 哪些技术领域出现明显需求？

输出：

[
{
"trend": "",
"evidence": "",
"reason": ""
}
]

4. 创业机会发现

根据用户痛点寻找产品机会。

每个机会输出：

* 产品方向
* 目标用户
* 用户痛点
* 当前替代方案
* 为什么现在值得做

5. 机会优先级排序

综合考虑：

* 出现频率
* 痛点强度
* 用户付费可能性
* 市场规模

输出：
记住内容文本要是中文的, key保持英文，比如下面的"pain_point"是英文, pain_point对应的内容是中文
Top 10 Opportunities：
[
{
"rank": 1,
"opportunity": "",
"target_users": "",
"pain_point": "",
"market_potential": 1-5,
"reason": ""
}
]

注意：

不要因为某一个热门帖子就判断为趋势。

只有多个独立讨论出现相似问题时，才认为是有效需求信号。

输入数据：

{story_analysis_results}
